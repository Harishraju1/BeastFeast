**A note about Raspberry Pi:** Raspberry Pi boards such as Pi 3, Pi 4 and Pi 5 are single-board computers that generally run Linux and can be controlled through a terminal. They are different from Arduino and ESP32 microcontroller boards. Raspberry Pi Pico is an RP2040 microcontroller board, but I have included it separately above so you can decide whether to stock it.

This master list is intended as a catalogue of possible components, not a recommendation to buy every item. Check the competition rules, voltage ratings, current ratings, physical dimensions and compatibility before procurement.
